# rushabhfulkari.github.io

My portfolio. One page, hand-written — no framework, no build step, no
dependencies beyond a webfont.

The type, the palette, the taped prints and the faces are all lifted from
[Cadence](https://github.com/rushabhfulkari/cadence), the Flutter reference app
it links to, because a portfolio that looks nothing like the work it is showing
is arguing against itself.

- `index.html` — the page
- `style.css` — Cadence's design tokens, ported to CSS custom properties
- `art/` — Open Peeps illustrations by Pablo Stanley, CC0 1.0

Both themes are solved for WCAG AA against their own surfaces, and the entrance
animations respect `prefers-reduced-motion`.
